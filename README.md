# AI 报告订单追溯链路

REQ-20261021-001 · Gate 2 产品评审站 · v1.2。

本仓库只发布该需求的可交互原型、Proposal 和评审记录，不包含其他项目。原型支持“同一订单多份 AI 报告”并行保留与分支切换：买家独立策略在报告生成前决定买家组，各报告拥有独立模型任务、输入、候选标签、阈值、报告和报价；成交买家确定后按其策略自动关联报告实例。所有订单、设备、买家、规则和金额均为脱敏演示数据；站点为纯静态页面，不连接真实后端。
